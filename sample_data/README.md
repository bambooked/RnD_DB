# サンプルデータセット

このディレクトリには、研究データ管理システムのデモ用サンプルデータが含まれています。

## 📊 含まれるデータ

### 論文 (Papers)
- **件数**: 3件
- **サイズ**: 1.2MB
- **形式**: PDF

### ポスター (Posters)
- **件数**: 2件
- **サイズ**: 1.7MB
- **形式**: PDF

### データセット (Datasets)
- **esg/**: 企業サステナビリティレポート（2件、9.5MB）
- **jbbq/**: バイアス研究データ（2件、6.5MB）
- **greendata/**: 環境排出量データ（2件、1.7MB）
- **cm-effect/**: CMエフェクトデータ（1件、120KB）
- **data-analysis/**: データ分析サンプル（2件、8KB）
- **dataset/**: サンプルデータセット（2件、8KB）

**合計**: 21MB

## 🚀 使い方

### セットアップ時に自動コピー

`setup.sh`を実行すると、このサンプルデータが自動的に`data/`ディレクトリにコピーされます：

```bash
./setup.sh
```

### 手動コピー

手動でコピーする場合：

```bash
cp -r sample_data/data/* data/
```

### Docker使用時

Docker Composeを使用する場合、ボリュームマウントにより`data/`ディレクトリが自動的に利用されます。

## 📝 注意事項

- このサンプルデータは実際の研究データの一部を軽量化したものです
- 本格的な利用には、独自の研究データを`data/`ディレクトリに配置してください
- Google Drive連携を使用すれば、より大規模なデータセットを管理できます

## 🔗 フルデータセット

より大規模なデータセットが必要な場合は、Google Drive連携機能を使用してください。
設定方法はメインREADMEを参照してください。
